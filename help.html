Mihomo Launcher — настройка за пару минут

Один раз настраиваете, какие программы и сайты работают через VPN и через какие узлы. Дальше — одна кнопка «Connect». Ниже — только нужное, без воды.

1 Быстрый старт ›
  1. Распакуйте архив и запустите MihomoLauncher.exe. При первом запуске он предложит скачать и настроить VPN-движок mihomo — согласитесь и подтвердите запрос Windows. Дальше движок поднимается сам.
  2. Откройте «Settings» → добавьте хотя бы один VPN-вариант (узел).
  3. Там же, в таблице «Правила», добавьте программы и сайты, которые должны работать через VPN.
  4. Закройте настройки и нажмите «Connect». Готово.
Защита включена сразу: пока вы не нажали «Connect», VPN-программы не выходят в интернет — реальный IP не светится.
2 VPN-варианты (узлы) ›

Settings → Основное → таблица «VPN-варианты»

  • «+ Добавить» → выберите тип: WireGuard (файл .conf), VLESS (ссылка vless://…), Hysteria2 (ссылка hysteria2://… или hy2://…) или Clash-подписка (URL).
  • В Hysteria2-ссылке лаунчер разбирает пароль, sni, обфускацию obfs=salamander, insecure, pinSHA256, alpn и «прыжки» по портам (mport или диапазон вместо порта).
  • Можно добавить несколько узлов — при подключении лаунчер сам подберёт рабочий для каждого правила.
  • Галочка «Вкл» временно выключает вариант, не удаляя его.
  • Кнопки «Выше / Ниже» задают порядок перебора.
  • Для Clash-подписки в окне варианта есть поле «Частота обновления (часов)» — как часто узлы из подписки заново скачиваются с сервера (по умолчанию раз в 48 часов).
  • Кнопка «Обновить списки» — стянуть свежую версию подписки с сервера прямо сейчас.
3 Правила: программы и сайты ›

Settings → Основное → таблица «Правила» → «+ Добавить»

Правило — это набор того, что открывается с одной плитки, с общими настройками VPN. В окне правила есть таблица «Что входит в правило», а под ней кнопки добавления:

  • «Приложение» — выбрать .exe через обзор.
  • «Процесс» — выбрать из уже запущенных программ.
  • «Store» — приложение из Microsoft Store (ChatGPT, Claude и т.п.) по стабильному идентификатору.
  • «URL» — сайт, который откроется по плитке.
  • «Шаблон URL» — готовый набор диапазонов сервиса (см. раздел ниже).
  • Колонка «Плитка» — что именно запускать/открывать по клику на плитке (можно отметить один пункт). Если не отмечено ничего — плитки на главном экране не будет, правило работает только для маршрутизации трафика.
  • Отметить «Плитку» можно и у строки-шаблона: своего адреса у шаблона нет, поэтому плитка откроет адрес для проверки подключения (например, instagram.com). Так плитка появляется и у правила, в котором есть только шаблон.
  • «Использовать VPN» — трафик правила идёт через VPN.
  • «Kill-switch» — пока VPN не поднят, у правила нет интернета (защита от утечки). Рекомендуется оставить включённым.
  • Иконка «с сервера» — тянется по названию правила; иначе укажите файл вручную.
4 Шаблоны диапазонов (blackmatrix7) ›

Чтобы через VPN шёл весь трафик сервиса (а не один адрес), добавьте в правило готовый шаблон диапазонов.

В окне правила → кнопка «Шаблон URL»

  • Найдите сервис по названию (YouTube, Instagram, Spotify…). В правило добавится строка-шаблон с диапазонами (домены + IP).
  • Кликнув по типу строки-шаблона, можно открыть её содержимое в браузере.
Шаблоны берутся из открытого репозитория blackmatrix7 — тысячи готовых сервисов с уже собранными диапазонами; списки сами обновляются.
5 Адрес для проверки доступности ›

По этому адресу лаунчер решает, открыта ли программа/сайт через выбранный VPN-узел.

  • Для известных сервисов подставляется автоматически.
  • Для неизвестных — можно оставить пустым: тогда правило просто привязывается к первому рабочему узлу без проверки сайта.
  • Можно вписать любой адрес вручную.
6 Какой VPN у какого правила (Routing) ›

Кнопка «Routing» на главном экране — вся схема одной таблицей: строки — правила, столбцы — ваши VPN-варианты.

  • Клик по квадратику ставит номер: 1 — первый вариант, 2 — запасной, и так далее. Повторный клик по номеру убирает его, остальные пересчитываются.
  • Пустой квадратик — этот VPN для правила не используется вообще.
  • Чтобы жёстко закрепить правило за одним узлом — поставьте номер только ему.
  • Отдельная колонка «Kill-switch» — та же галочка, что в окне правила (см. раздел ниже).
  • Если у правила не отмечен ни один VPN, а «Использовать VPN» включено — на плитке будет статус «Не выбран VPN».
То же самое есть и внутри правила: Settings → правило → «Какие VPN-варианты можно использовать». Таблица «Routing» просто показывает все правила сразу — удобнее, когда узлов и правил много.
7 Подключение и главный экран ›
  • «Connect» — лаунчер подбирает рабочий узел для каждого правила и открывает доступ.
  • «Disconnect» — разорвать соединение и снова включить защиту (kill-switch).
  • «Routing» — таблица «какое правило через какой VPN и в каком порядке» (раздел 6).
  • Значок журнала в заголовке окна — живой лог «Что заблокировано и почему» (раздел 9).
  • Плитка показывает узел и страну/город сервера. Клик по плитке открывает программу или сайт.
  • Угловые значки на плитке: ⚙ (слева сверху) — изменить правило; ⟳ — переподключить только эту; ✕ — отключить только эту.
  • Подписи под плиткой: «напрямую» (без VPN), «нужен VPN» (ещё не подключались), «не работает» (ни один узел не открыл сайт), «Не выбран VPN» (сняты все варианты).
  • Если узел не отозвался с первого раза, лаунчер не сдаётся: несколько попыток, два прохода по списку узлов и автоповтор примерно раз в 90 секунд.
8 Kill-switch: защита от утечки ›

Защита работает в два слоя, и включается она по правилам — у каждого правила своя галочка «Kill-switch».

  • Внутри движка. Пока ни один VPN-вариант правила не поднялся, трафик правила отклоняется, а не уходит напрямую. Работает, только пока движок жив.
  • Брандмауэр Windows. Переключатель «Блокировать программы средствами Windows, когда туннель недоступен» в Settings → Mihomo. Программы из правил с kill-switch не выйдут в интернет мимо туннеля, даже если движок упал, перезапускается или лаунчер закрыт.
  • Строка под переключателем показывает состояние: сколько правил в брандмауэре или что нужна установка (кнопка «Настроить mihomo» — одно окно UAC).
  • Локальная сеть, принтеры и удалённый рабочий стол не блокируются никогда.
  • Брандмауэр умеет закрывать только программы. Если в правиле один сайт или шаблон и ни одной программы — закрывать нечего, добавьте в правило программу, которая его открывает.
Защита включена с момента входа в систему, даже если программу запустили мимо лаунчера.
9 «Что заблокировано и почему» (живой лог) ›

Значок журнала в заголовке главного окна

Сюда смотрят, когда сайт или программа не открывается. Пока окно открыто, движок пишет подробный лог; откройте проблемную ссылку — строка появится в списке с готовым объяснением.

  • «Проблемы» — то, к чему причастна утилита: её правила, kill-switch, отказавшие узлы и DNS.
  • «Реклама и трекеры» — что вырезал DNS-сервер вашего компьютера (роутер, провайдер, NextDNS/AdGuard). Это норма, а не сбой.
  • «Мимо утилиты» — прямые соединения программ, не попавшие ни под одно правило: не дозвонилась сама программа, утилита ни при чём.
  • «Всё подряд» — включая успешно пропущенное.
История живёт вместе с утилитой: подключения и переподключения её не стирают. Кнопка «Очистить» — если хочется начать с чистого листа.
10 Remote desktop session (удалённая настройка) ›

Переключатель-страховка на случай, когда лаунчер настраивают по удалённому рабочему столу (RDP, AnyDesk и т.п.): неверная настройка VPN может оборвать удалённое подключение, а этот режим не даст «закрыть себе доступ».

  • Пока режим включён, лаунчер каждые 60 секунд останавливает движок mihomo, если тот запущен. Если связь пропала из-за VPN — доступ вернётся не позже чем через минуту.
  • Переключатель есть в трёх местах (они синхронизированы): на главном экране рядом с кнопками, в Settings → Mihomo и в окне установки движка.
  • Рядом виден отсчёт; он идёт только пока движок реально запущен.
  • Адреса активной RDP-сессии лаунчер и так находит сам и держит вне туннеля и вне блокировок, так что обычно связь не рвётся и без этого режима. Он — страховка от совсем неудачного конфига.
  • По умолчанию режим выключен. Закончив удалённую настройку, выключите его.
11 Движок, автозапуск, обновления ›

Settings → вкладки «Mihomo» и «Настройки»

  • Движок mihomo скачивается автоматически — при первом запуске (с вашего согласия) или кнопкой «Настроить mihomo» на вкладке Mihomo. Берётся последняя стабильная версия с GitHub. Если движка нет — статус показывает «Не установлен».
  • Путь к mihomo и рабочая папка по умолчанию — в папке DataUser рядом с программой; обычно менять не нужно.
  • «Запускать при включении компьютера» (вкладка Настройки) — автозапуск лаунчера при входе в систему. Окно при этом не открывается: программа сворачивается в трей (значок у часов) и сама подключается. Наведите курсор на значок — во всплывающей подсказке видно состояние; клик по значку открывает окно.
  • Путь к файлу конфигурации (вкладка Настройки) — можно перенести настройки в своё расположение.
  • Когда выходит обновление лаунчера, движка или гео-базы — на главном экране появляется зелёная кнопка «Обновить». На вкладке «Обновление» видно версию и дату каждого, свой период проверки и кнопка обновить принудительно.
  • Если движок ведёт себя странно (не отвечает, не ставится) — кнопка «Переустановить движок» сносит его и ставит заново.
12 Полное удаление ›

Рядом с MihomoLauncher.exe лежит uninstall — запустите его, и откроется окно удаления с кнопкой «Удалить».

  • Оно по шагам закроет программу, остановит VPN (mihomo), уберёт лаунчер из автозапуска, удалит задачу планировщика (здесь появится запрос прав администратора — подтвердите) и сотрёт служебные данные.
  • Последний шаг делаете вы: папку с программой удалите вручную. Вместе с ней уходит и папка DataUser, где лежат ваши настройки, гео-база и сам движок.
  • Пока папка на месте, ваши правила и узлы сохраняются — удаление служебных данных их не трогает.
Если приложение «не запускается» после переустановки — частая причина в том, что старая копия ещё работает в фоне. Удаление очищает это состояние; затем распакуйте новую версию и запустите снова.
