## Что это

Mihomo Launcher рассчитан на нетехнического пользователя: вы один раз настраиваете, *какие программы и сайты ходят через VPN и через какие узлы*, а пользователь просто жмёт **Подключиться**. Лаунчер поднимает туннели, проверяет доступ и открывает программы.

## Ключевые возможности

- **Правило = приложение + диапазоны IP/доменов.** Главная фишка. В одном правиле и само приложение (или сайт), и его диапазоны адресов — добавьте готовый шаблон сервиса, и **весь** его трафик пойдёт в один туннель. Реальный IP не утечёт «мимо» правила.
- **Готовые шаблоны диапазонов.** Целые наборы доменных/IP-правил из открытого репозитория [blackmatrix7 / ios_rule_script](https://github.com/blackmatrix7/ios_rule_script) — тысячи сервисов, поиск по названию, автообновление.
- **Свой туннель у каждого правила.** Несколько узлов работают одновременно: одно приложение — через Францию, другое — через Германию, третье — напрямую. mihomo (Clash.Meta) держит несколько userspace-WireGuard туннелей сразу, без лимита «один туннель».
- **Разные типы VPN-источников.** WireGuard `.conf`, `vless://` (VLESS / Reality), Clash/mihomo-подписки.
- **Постоянный kill-switch.** На каждом правиле. Пока VPN не поднят, VPN-приложение без интернета — трафик отклоняется движком, а не идёт напрямую. Упавший узел не светит реальный IP.
- **Безопасный режим «Remote desktop session».** Переключатель для настройки лаунчера по RDP / AnyDesk: пока включён, движок останавливается каждые 60 секунд, если запущен, — кривой VPN-конфиг не заблокирует доступ, связь вернётся за минуту.
- **Проверка соединения по отклику сайта.** Доступность определяется по телу ответа (блок-маркеры), а не по коду статуса — Cloudflare-403 не путается с реальной блокировкой. Лаунчер сам перебирает десятки узлов, пока сервис не откроется.
- **Приложения из Microsoft Store** (ChatGPT, Claude, …) через стабильный AUMID, плюс обычные `.exe` и сайты.
- **Геолокация сервера на каждой плитке** (страна, город) по локальной базе MaxMind GeoLite2 — полностью офлайн.
- **Двуязычный интерфейс (RU / EN)**, переключение на лету.
- **Встроенное онлайн-обновление** лаунчера, движка mihomo и базы геолокации.

## Как это работает

Каждое правило объединяет цель (приложение, сайт или Store-приложение по AUMID) и её диапазоны доменов/IP. При нажатии **Подключиться** лаунчер для каждого VPN-узла по очереди собирает конфиг: уже закреплённые правила остаются на своих узлах, а остальные (и сам лаунчер) пробуют текущий. Доступность проверяется по телу ответа, рабочий узел закрепляется, остальные едут дальше — так перебираются десятки узлов, пока всё не откроется. Что не подошло ни под один узел — остаётся под kill-switch (отклоняется), а не идёт напрямую. Геолокация сервера — по локальным базам MaxMind, без обращений в облако.

## Требования

- Windows 10 или 11 (x64)
- .NET Framework 4.8 (есть в Windows; ставится автоматически, если отсутствует)
- Свои VPN-узлы (WireGuard `.conf`, ссылка `vless://` или Clash/mihomo-подписка)

## Вопросы

**Не утекает ли реальный IP?** Нет. Правило отправляет *весь* сервис (приложение + его диапазоны) в один туннель, а kill-switch блокирует VPN-приложения, когда туннель не поднят.

**Какой движок?** [mihomo](https://github.com/MetaCubeX/mihomo) (Clash.Meta) — WireGuard, VLESS/Reality, TUN, маршрутизация по процессу и домену. Несколько туннелей одновременно.

**Бесплатно? Телеметрия?** Бесплатно, без телеметрии. Геолокация — локальная база MaxMind GeoLite2; конфиг хранится на вашей машине. В интернет лаунчер ходит только за обновлениями (с вашего подтверждения) и за списками правил.
