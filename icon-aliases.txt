# Tile icon aliases — hand-maintained. build\gen-icons.ps1 merges this with the file list of
# ico_web\ (the icon set uploaded to https://byfox.dev/data/mihomolauncher/ico/) into the
# shipped icons.txt. IconFetcher recognises a rule by: its name, its programs' exe names,
# its sites' domains, its blackmatrix7 template name and the template's domains.
#
#   key=slug           a rule name / exe name / domain label that means this icon
#   @domain=slug       this domain AND all its subdomains mean this icon (longest wins)
#
# Keys are case-insensitive. Anything already named exactly like an icon file (youtube,
# telegram, chatgpt…) needs no line here.
